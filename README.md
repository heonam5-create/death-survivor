# 데스 서바이버 확장팩

설치 없이 바로 플레이하는 모바일 생존 슈팅 웹게임 (현대 화기 280종 · 40스테이지 · 탑승 장비 120종 · AI 동료 구출 · 난이도 4단계)

- 게임 주소: https://heonam5-create.github.io/death-survivor/
- 카카오톡에 위 주소를 보내면, 받은 사람이 링크를 한 번 눌러 바로 플레이할 수 있습니다.

## 확장팩 v7 업데이트
- 난이도 재조정(쉬움 85%/80% · 보통 120%/115% · 어려움 165%/150% · 지옥 230%/190%), 기본값 보통, 일시정지 메뉴에서 진행 유지한 채 변경
- 40개 보스 체력 v6 대비 정확히 3배, 모두 3줄 체력바(빨강·주황·보라), 10가지 유형별 고유 패턴 + 3페이즈 고유 필살기
- 보스 처치 시 적 공격 정지 + 화면 밖 보석까지 전부 흡수 회수 → 클리어 화면 (자동 진행 없음)
- 클리어 화면: 골드 강화 + 무기 최대 2개 계승 선택 + '다음 스테이지' 버튼
- 성장도(강화·무기·계승·동료)에 따라 적 강도 자동 조정(난이도별 상한)
- 차량 자동 탑승 전용(탑승 버튼 제거), 차량 무기 발사체·폭발 대폭 강화(보스에는 50% 피해)
- 버그 수정: 동료 합동 공격과 콤보 타이머 변수 충돌로 멈출 수 있던 문제

## 확장팩 v6 업데이트
- 최종 보스 총 체력 2.5배 + 2~3줄 색상 체력바(빨강→주황→보라), 체력바 전환 시 경직·연출·페이즈 변화
- 보스 처치 후 무기 1개 계승 (레벨·진화 유지, 저장됨, 다음 클리어 때 다시 선택)
- 전체 난이도 소폭 상향 (적 공격력·등장 수 +7%, 이동속도 +3%, 정예 기술 주기 -10%, 후반 몬스터 조합 다양화)
- 차량 근접 자동 탑승, 차량 발사체·폭발 대형화, 탑승 중 연쇄 폭발 강화, 차체별 발사음
- 골드 강화·계승 무기 기반 다음 스테이지 난이도 보정 (난이도별 상한 15~25%, 미강화 시 0%)

## 확장팩 (v5) 업데이트
- 게임 제목 「데스 서바이버 확장팩」, 기본 난이도(보통) 약 15~20% 상향 (적 수·정예 빈도·공격 패턴 위주)
- 타격감: 무기 계열별 명중 이펙트, 피격 경직, 폭발 충격파·파편, 연쇄 폭발, 콤보(10·30·50·100), 화면 흔들림 강도 설정
- 탑승 장비: 내구도 약 35% 하향, 사용시간 20~40초, 진행률 45~75%에 낙하산 투하, 차체별 전용 무기·스테이지 등급별 진화, 1회 필살기
- 신규 무기 80종 (스테이지마다 2종, 총 360종), AI 동료 성장(주인공 성장의 50%) + 계급별 무기 강화
- 스테이지별 고유 정예 40종 (14가지 기술, 경고 표시, 주변 강화·포위 이동), 정예 처치 보상 선택, 무기 보급 상자
- 스테이지 테마별 폭발·처치 연출, 30FPS 절약 모드, 입자 오브젝트 풀링, 이펙트 상한·화면 밖 생략

## v4 업데이트
- 난이도 4단계 (쉬움·보통·어려움·지옥) — 스테이지 선택 화면과 일시정지 메뉴에서 언제든 변경
- 스테이지마다 탑승 장비 3종 (총 120종: 차체 17종 × 무기 14종 × 특수능력 12종 × 부착물 조합)
- AI 동료 10계열 구출 · 동료 합동 공격 · 차량 동승/호위/공중 지원
- 회복 물약 맵 리젠 · 보스 강화(2페이즈·새 패턴·약점 노출) · 랜덤 전장 이벤트 · 특별 임무

## 파일 구성
- `index.html` — 게임 전체 (한 파일)
- `og.jpg` — 카카오톡/SNS 링크 미리보기 이미지
- `icon-*.png`, `apple-touch-icon.png`, `manifest.webmanifest` — 홈 화면 아이콘
- `source/` — 수정용 원본 코드 (`python3 build.py` 실행 시 `index.html` 생성)

## 업데이트 방법
`main` 브랜치에 새 `index.html`을 올리면 1~2분 뒤 GitHub Pages가 자동으로 새 버전을 배포합니다.

## 카카오톡 공유 API (선택)
`index.html` 안의 `kakaoKey: ''` 칸에 카카오 개발자 사이트의 JavaScript 키를 넣으면
'카카오톡 공유' 버튼이 카카오톡 공유 창을 바로 엽니다. 키가 없으면 휴대폰 기본 공유창 또는 링크 복사로 동작합니다.
